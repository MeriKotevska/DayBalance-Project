Database tools

Technical controls for the DayBalance data store.

Database operations
Use these controls to reset and seed the application's MongoDB database. Resetting removes all data from all collections. Seeding inserts realistic DayBalance sample data (categories, users, habits, completions, tips, and activity history).

Reset the database?

Are you sure you want to reset the database? This will remove all existing data.
